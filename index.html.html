Pipeline Design

Automated refresh orchestration.

Sequential dependency — Step 2 only fires after Step 1 succeeds.

1
Hr_Dataflow
Dataflow Gen2 refresh — pulls and transforms latest source data into the Lakehouse Delta table
✓
Success gate
Step 2 triggers only after Step 1 completes without error — prevents stale data in reports
2
HR_Semantic_Model_Refresh
Semantic Model picks up fresh Lakehouse data — Power BI report stays in sync automatically
